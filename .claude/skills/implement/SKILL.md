# Implement Plan

1. Read the plan file specified by the user (or the most recent TODO/plan doc)
2. Implement ALL items in the plan, not just the first few
3. After each file change, run `cargo check`
4. After all changes, run `cargo test`
5. Report: what was implemented, what tests pass, what the user will see differently
6. Do NOT stop at planning — execute the full implementation
